# Carpeta capturas

Según la consigna de la Actividad 9, aquí debe ir:

```
capturas/
└── matriz_ejecucion.png   <-- Captura mostrando la ejecución en consola
```

## Qué hacer

1. Compila y ejecuta `src/main.cpp`.
2. Toma una captura de pantalla (screenshot) de la consola mostrando la salida del programa.
3. Guarda la imagen como `matriz_ejecucion.png` dentro de esta carpeta.
4. Esta captura se adjunta al informe APA v7 (`docs/`) como evidencia de la ejecución.

> Nota: este archivo `.gitkeep` solo sirve para que Git rastree la carpeta vacía hasta que agregues la imagen real.
