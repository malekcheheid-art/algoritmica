## Descripción

Esta actividad busca desacoplar el razonamiento lógico del lenguaje de programación (C, C++, Python, etc.).
Antes de escribir código en una computadora, el programador debe ser capaz de:

1. Entender y diseñar la secuencia algorítmica mediante diagramas de flujo universales.
2. Simular la memoria RAM y el procesador en papel mediante la Prueba de Escritorio (Dry Run).
3. Comprender que variables, condicionales, bucles y vectores son conceptos abstractos e independientes de cualquier IDE o entorno.
